# FisioSea Gift Card

Página estática para validar Gift Cards mediante un código único.

## Cómo funciona

El QR debe apuntar a una URL como:

`https://TU-USUARIO.github.io/?codigo=FS-001`

La página lee el código y muestra el certificado como "SERVICIO PAGADO" si existe en `app.js`.

## Importante

Esto es una primera versión. Los códigos están escritos en JavaScript, por lo que no debe considerarse un sistema de seguridad de nivel empresarial.

## Publicación

Puedes subir estos archivos a GitHub y activar GitHub Pages.
